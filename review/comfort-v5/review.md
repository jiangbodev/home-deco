# 椅子、地毯、书籍、卫浴和壁龛修整

基线为本地提交55f6320；用户授权修复和提升细节，未要求本轮发布。施工图和平面布局沿用已审核版本，不改建筑开口、家具位置、导航或灯具。

## 本轮范围与验收要求

- 主卧仅一把书桌椅：消除马蹄形硬壳、下端缺口；软包靠背与座面实际相交，四脚保持地面接触。约45cm宽、81cm高，不占额外通道。
- 保留原素色地毯：短绒细节随距离抗混叠淡出，圆润窄包边；无逐根毛发或实时附加渲染通道。
- 书架每组纸页块按各自厚度轴写入UV，纸页分层细纹与封面织物微纹理；保留已有书脊印字、差异化书宽/堆放和色彩。卧室层板上的两组书和两只碗按用户后续要求全部隐藏。
- 两卫马桶保留原外轮廓和壁挂位置，重做略带弧度的薄盖板，单独使用热固性座盖材质；主卫五金统一为金属。浴缸保持既有圆角内腔、外包尺寸，外裙和缸沿增加2mm倒圆。
- 壁龛侧端原先有一张面伸出实体约262mm，形成不闭合薄片。重建闭合L形回折体，连续内侧面不变；背板保持同一38号乳白材质，收口增加小倒圆。最终加载光照后复查：竖边保持同一乳白色，保留窄倒圆边上的正常受光差异，没有用异色贴面遮盖。

## 验证

- Blender 作者网格的椅子、地毯包边、壁龛和马桶盖板闭合性通过；最终 GLB/12个模块一致性通过，validator 0 errors。
- 1453 个网格节点，1410 个未修改网格包围盒完全一致；原节点矩阵和交互元数据保留。4 个主卧陈设节点仅隐藏。
- 全屋 652882 三角形，比基线增加1772（约0.27%）。模型、光照和反射资源共13,074,042 bytes，比基线减少18,601 bytes。
- 生产构建和加载进度检查通过。检查了椅子正/侧/背面、主卧空层板、两卫马桶、浴缸、地毯、书籍和壁龛最终实景；截图在本目录。
- 最终重算路径：qa/comfort-v5/daylight-v3、baked-v3、probes-v3。v1/v2中间结果不用于发布。
- Apple M4 / 1675×1432，完整加载后客厅6秒小范围移动和转向采样：中位16.7ms，P95 17.7ms，557 draw calls；这是本机短程采样，不代表手机或全屋长时测试。浏览器 error 日志为空。详细见 performance.json。
