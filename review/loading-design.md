# Loading design

Warm ivory background, olive progress indicator and a small inline SVG architectural illustration. No external image/font downloads. Real model/texture byte progress remains unchanged; light preparation is indeterminate rather than a synthetic percentage. Desktop uses a two-column layout, narrow screens a stacked layout. Loading remains scrollable in short viewports; retry keeps its existing handler.

Checked visual download and failure fixtures at 1280×900, 390×844, 320×568 and 844×390. Fixture screenshots deliberately use a fixed 43% to review layout; production still derives progress from resource events. Startup delayed-light and failed-light browser checks passed, including matching first/settled frames. Loading progress regression and build passed.
