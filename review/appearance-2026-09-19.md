# 漫游真实感：第一轮改进

范围：用户授权按光影、材质、局部细节顺序改善现有漫游，保留分房间加载、相邻房间预加载和 20 MB 资源上限。户型、门窗、家具摆位及修复后的床品几何不变。

## 1. 光影

- 从现有完整 GLB 的实际三角面离线追踪半球射线，生成地面接触遮蔽图，以及 98 个固定墙体/柜体对象的六面投影遮蔽图。
- 地面 768×512，48 样本，0.85 m 半径；墙柜图集 1024×2048，48 样本，0.5 m 半径。
- 地面图的红通道为固定几何，绿通道为默认可见家具。门、可移动窗、隐私帘、隐藏门、吊顶和透明物体不参与遮蔽烘焙。
- 家具、钢琴或餐椅状态偏离初始状态时关闭家具阴影通道，避免残影；恢复初始状态后重新启用。此轮不为每种组合烘焙独立阴影，非默认家具状态仍保留固定构件阴影。
- 全部模块到齐、对应贴图可用且模块文件版本匹配后启用。图像在首次画面显示后加载；可选资源失败不会阻止漫游。模型模块变化后 CI 要求重新烘焙，运行时也拒绝使用不匹配的旧阴影。
- 不增加实时投影或全屏后处理。环境光 1.6→1.3，环境贴图强度 0.8→0.75，方向光 2.2→1.85，曝光 1.05→1.0。

## 2. 材质和局部细节

- 仅对高亮、无颜色贴图、不透明的非金属哑光表面降低 14% 线性色反射率，收敛白色漆面。
- 复用已有胡桃木/橡木扫描贴图；法线强度乘 1.5，粗糙度系数调为 0.9。
- 仅对六个已修复床品材质增强已有法线细节 35%；保留原有织物柔光、纹理比例、几何褶皱和所有原始网格数据。
- 没有增加全屋模型面数或生成替代家具。植物和部分原本简化的家具外形仍限制最终真实度，本轮不声称达到照片级效果。

## 3. 验证

- 玄关、客厅、主卧、次卧使用相同生产漫游视角截图对照，检查柜内、墙角、床边和布料；未发现床品黑洞回归。
- 生产着色器浏览器检查无页面或着色器错误；家具/钢琴/餐椅切换与恢复、门开关、未完成加载和模型版本不匹配的保护均通过。
- 同一客厅视角开启/关闭烘焙效果均为 1752 次绘制、1,215,950 个三角形；实时阴影开关关闭。该结果证明新增效果没有额外几何/阴影绘制，不等于手机 FPS 测试。
- 模型与共享贴图仍为 9,103,195 字节；包括四个新烘焙文件共 9,761,292 字节。新纹理不使用 mipmap，估算 GPU RGBA 存储新增约 9.5 MiB。
- 浏览器使用软件渲染，因此不报告或承诺真实手机帧率。需要实际手机漫游确认。

## 重新烘焙

使用与当前模块几何完全匹配的完整源 GLB，不要再次减面。先验证源与模块，然后烘焙：

```sh
node scripts/verify-modules.mjs /path/to/lossless-full-source.glb
node scripts/bake-floor-contact.mjs /path/to/lossless-full-source.glb
npm run build
node scripts/check-model-budget.mjs
```

输出位于 `public/assets/lighting/`。发布前删除不再被两份 JSON 引用的旧哈希图片，重新检查同视角与所有家具交互状态。

## 后续：墙面与柜面仍然偏平的反馈

第一轮的接触阴影没有补足表面材质。此轮对明确的墙体与漆面柜体材质 ID 添加独立处理，保持玻璃、石材、织物和陈设原材质：

- 墙体采用细颗粒哑光表面，粗糙度 0.9；柜面采用暖象牙白漆面，粗糙度 0.43，保留较柔和的反光。
- 共用 256×256、178,389 字节的三通道材质数据图，分别控制轻微色差、微观起伏和粗糙度。纹理按世界米制投影，使用 mipmap 减少远处颗粒闪烁。
- 首轮颗粒在墙面显得斑驳，已将墙面高度系数由 0.7 mm 降至 0.32 mm、色差系数由 12% 降至 5.5%；柜面高度系数为 0.12 mm。
- 与原有烘焙接触阴影叠加，材质图在首帧后异步加载；失败时保留基础颜色和粗糙度。无新增几何、绘制通道或实时阴影。
- 总模型、光影、材质数据约 9,939,681 字节；本轮额外 GPU RGBA+mipmap 存储约 0.33 MiB。实际手机帧率仍未测量。
- 玄关、客厅、主卧、次卧的生产视角和柜面近景完成浏览器检查，无页面或着色器编译错误。
