# 餐厅真实性样板区 · 本地验收

以本地原图 04-餐厅、06-客厅为参考，完成一轮餐厅样板改进。原图属于用户私有资料，保留在忽略的 reference/装修材料；本轮没有提交或发布。

## 实际改变

- Blender 重建网页真正显示的餐桌：45 mm 台面、4.5 mm 边缘倒角、收腰实木支撑、底脚及连接横梁；仍为长 1.77 m、高 0.75 m，布局不变。
- 餐椅由平直椭圆靠背改成弯曲的包围式藤编，使用实际镂空交织条、弯木边框、端柱和支撑。移除 88 个被替代的旧装饰条，圆木腿保留轻微外张。清掉旧坐垫遮蔽贴图，消除不对应新椅架的暗斑。
- 校正桌椅和长凳木纹方向、尺度及 UV 通道，恢复纹理反差，减弱过于干涩的表面，保留自然粗糙度变化。
- 乳白柜面保留更多烘焙体积阴影；弧面仍使用连续材质，避免重现分块色差。光照保留更多真实暖色反弹，整体曝光从 1 调到 1.15。
- 所有接触阴影、Cycles 间接光、局部 HDR 反射均从最终 v3 模型重建；不增加漫游中的实时阴影或反射通道。

## 性能与完整性

Apple M4，本地同一浏览器、六秒移动和转向轨迹、1675×1432 渲染分辨率，去掉前 0.5 秒：

| 指标 | 原版 | 新版 |
| --- | ---: | ---: |
| 中位帧时间 | 16.7 ms | 16.7 ms |
| 95% 帧时间 | 16.8 ms | 16.8 ms |
| 末帧绘制调用 | 1060 | 1068 |
| 末帧可见三角形 | 384,934 | 375,066 |
| 全模型三角形 | 615,852 | 610,918 |
| 模型、纹理、清单 | 7,183,234 B | 7,167,442 B |

该测试约 60 FPS，没有测出回退，但不代表所有设备均有同样表现。增加的绘制调用来自藤条材质分组；场景资源净增加仅 15 KB。一次本地开发缓存加载到准备完成约 1.33 秒，仅用于本机检查，不是线上冷启动速度承诺。

- 1413 个网格节点、12 个模块，glTF 验证零错误，模块与最终源的解码几何一致。
- 所有原有节点变换、交互数据及未修改家具边界保留；1407 个其他网格边界一致。
- 纹理 UV 通道有效，坐垫旧 AO 已去除；光照模块版本及 irradiance 源 SHA256 匹配。
- 生产构建、资源完整性、加载进度逻辑通过。实际打开本地生产预览，loading 后进入带完整光照的玄关，控制台无错误，页面无开发面板。37 个未引用的旧资源移到忽略的 qa/dining-study-stale-assets，可恢复。

## 与原效果图仍存在的差距

这轮主要改善家具构造、木材和光照层次，没有达到离线效果图的全部细腻程度。原图还有更丰富的木纹、经过布置的陈列和高采样多次反射。网页仍使用局部静态反射与投影光照图，在镜面、复杂曲面和近距离微细节上存在近似；门窗交互改变场景时继续沿用原来的光照回退机制。桌面保持用户指定的无花瓶状态，不为了复刻效果图添加摆件或改变布局。

后续最有价值的是按家具材质建立专用 UV 和更完整的木纹/粗糙度贴图，再以样板方式扩展其他区域，而非单纯堆三角形或继续全局加亮。
