# 客厅、餐厅、阳台：图纸优先核对

本轮接续厨房和双卫修复，仍为本地工作，未提交/发布。按03平面布置、15/16/17施工立面及07天花布置核对，再看03–08效果图。私人原图保留在忽略的 reference/ 和 qa/，不复制到公开报告。

## 核对与修复

| 区域 | 依据与发现 | 处理 |
| --- | --- | --- |
| 阳台窗台 | 16立面明确标注定制石材窗台，模型只有窗下抹灰实体 | Blender新增20毫米石材台面，落在580毫米既有窗下墙上，上沿600毫米，不遮挡玻璃，止于洗衣柜前沿 |
| 客厅书柜端部 | 书架主体是奶油色柜体，沙发侧60毫米圆角收口仍用另一材质和箱形光照 | 收口及同类入门侧收口统一为材质38，并沿用柜体连续光照处理，避免曲面与正面割裂 |
| 餐椅 | 两把在用椅子的木框脚离地约12毫米 | 仅延伸底部45毫米内的腿端，座高、靠背、编织和交互矩阵不变 |
| 餐厅吊灯 | 木灯座与灯口间有约3.5毫米空隙 | 补实际连接套，原吊线、顶盖、灯泡及光源位置不变 |
| 阳台洗衣区 | 平面为并排洗衣/干衣机与上方壁挂机；位置已有，但舱口为圆环贴在未开孔盒体上 | 对三台机身做真实布尔凹口；补凹入门玻璃、内圈、旋钮/抽屉及支脚，壁挂机补连接墙面的固定座 |
| 隐藏门设置 | 页面勾选“展开”时实际为关闭，因为源数据 on 表示门关闭 | 仅反转洗衣门开关的UI映射；保留原开合矩阵与初始关闭状态 |

窗台厚度、家电型号、门圈/安装细节未获施工详图定尺，属于在图纸边界内的合理细化，不是厂家安装方案。门玻璃用不透射的深色抛光材质表达凹入舱口，不额外增加透明渲染通道。

## 核对后保留

- 餐桌现有外包约1770×850×750毫米、临墙端、厨房内窗/台面关系保留。平面和效果图画四把椅子，但模型元数据记录用户确认长凳，因此保留两椅加条凳及其收纳状态，不覆盖后续偏好。
- 南侧通高柜约2035毫米、书架外包1705毫米（内净约1625毫米）、高2370毫米；立面的柜体分格与总体关系已有对应。图纸栅格/门板细节有示意成分，不通过拉伸建筑边界强行对齐像素。
- 沙发位、电视矮柜、钢琴、主卧阳台门和洗衣隐藏门布局保留；三坐垫暖白沙发、吊装投影、空餐桌、1.4米视高等用户后续要求优先于旧效果图。
- 天花图为客餐厅中部原顶、周边局部吊顶及阳台分区。已核对现有顶部/风口/窗洞关系，本轮不擅自新增一层整屋吊顶或移动门洞。
- 效果图中的软装陈列、单椅和钢琴造型并不等同于施工布局错误；此轮不添加无依据的摆件填满通道。独立单椅、钢琴更精细外形仍是后续外观提升项。

## 制作与验证

不可变输入：qa/living-plan/before.glb 与 original/modules，包含前一轮湿区修复。编辑源 source/home-deco-living-plan.blend；脚本 scripts/blender-living-plan.py；最终拼装 qa/living-plan/source.glb。

check-living-plan.mjs 检查原节点矩阵/附加数据、无关网格边界、窗台接触与玻璃净空、柜体材质、椅脚贴地、三台设备真实凹口射线及壁挂固定座触墙。测试对共享 POSITION 数组使用副本，避免第一台机的检测修改第二台共用顶点数据。没有通过放松阈值绕过失败。

本轮增加5060个三角形，总计626682；1415个无关网格边界保持。完整接触、备用照明、物体遮蔽、Cycles漫反射和HDR探针从本轮源重新生成。

首次导出校验发现两块收口缺少柜体粗糙度贴图所需UV，已在Blender源补齐；最终模块校验为1433个mesh节点、12个模块、0错误。首次照明结果保存在qa/living-plan/uv-incomplete-bakes，仅作中间记录，不用于最终版本。

浏览器已确认洗衣门默认关闭时“展开”开关不勾选；勾选后门板移至侧面、三台设备可见；取消后重新合上，原门板矩阵和初始状态保留。新配件不随门板移动，不穿出关闭的门面。

最终生产构建与加载进度检查通过，完整外观资源13,036,836字节（约13.04MB），比上一轮增加37,485字节；22个旧文件已移到本地qa备份。没有新增实时灯光、镜面或透射渲染通道。构建仍有既有Three.js主包超过500KB的提示，不影响构建结果。

## 地毯与朝沙发一面的木柜材质补充

地毯保留原贴图，叠加按世界尺寸计算的细微交错编织起伏，并用像素导数降低远处高频纹理，避免加几何。电视柜及沙发边柜单独降低木色饱和度、提亮，并减弱过深的烘焙暗部；其他房间共用的木材不受影响。两柜采用40%原烘焙漫反射与60%连续照明混合，仍保留接触阴影。这属于运行时材质校准，不是新增Blender模型或新的物理光照烘焙。
