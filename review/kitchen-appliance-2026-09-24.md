# 厨房烟机、灶台与客厅弧形柜格局部修整

以 `qa/desk-v6/source.glb` 和同版本模块为不可变输入，使用 `scripts/blender-refine-kitchen-appliances.py` 在 Blender 中修整。厨房参考为本地 `reference/装修材料/效果图/09-厨房.jpg`；参考资料未加入仓库。

- 烟机原来的大块黑玻璃缺乏进风结构。调整为烟灰玻璃、金属控制横条、单组斜面滤网和下沿灯罩，保留原有安装尺寸及橱柜关系。原来的 23 根栅条、长条进风口及 3 个控制示意点与新滤网处于相同深度，已隐藏，避免两层栅条交错和闪烁。
- 双眼燃气灶保留原嵌入开口，补上金属周边、燃烧器环、点火针和旋钮刻度。一个炖锅仍在炉头上；平底锅移到相邻台面，留出一个可见炉头，锅底与台面约 3 mm 间隙。
- 客厅弧形柜格的侧板原为 L 形回折；更关键的是洗衣区结构柱与三段弧形柜壳重叠，前缘表面仅相隔约 0.1 mm，走动时产生深度冲突。将柜壳、结构柱、两层侧边及背板在 Blender 中布尔并为一块实体，清除相交的内部表面，重算法线，保留原开口和弧形层板。其余七个旧柜格节点隐藏，避免再次叠画。

厨房运行画面已从正面和偏右视角检查；灶台轮廓与烟机滤网可辨认。旧栅条和控制点共 27 个节点的 `source_visible` 均为 `false`。弧形柜体合并后为封闭网格，非流形边和退化面均为 0；相机转向检查时，之前的密集条纹消失。最终几何的 glTF 校验为 0 错误，接触阴影、日光和局部反射已重烘。`npm run build`、`check-model-budget.mjs` 均通过，完整资源为 13,192,044 字节；本地页面无控制台错误。
