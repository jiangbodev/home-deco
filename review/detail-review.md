# 本地模型真实性改进

范围：餐桌与餐厅、电视、客厅柜体、次卫，并按后续要求检查书桌、椅子、梳洗区、厨房及全屋门窗。目标是让物件的尺度、构造和表面反应更可信，不改变已经确认的户型与家具布局。本轮在本地完成，不自动提交或发布。

## 主要变化

- 电视从绿色哑光平板改成 16:9 黑色屏幕、细边框、背部支架与表面玻璃。投影机从条形占位物改为带镜头开口和散热口的机身。
- 餐桌用 40 mm 木台面、6 mm 圆角和连接支撑；书桌为 32 mm 台面与较轻的边缘圆角，重新整理木纹坐标。保留藤编餐椅，收窄书桌椅上部轮廓，细化条凳腿。
- 客厅木柜保留扫描木纹，校准底色、粗糙度与旧 AO；通高乳白柜增加内退踢脚，保留门缝和乳白色。
- 马桶、盆腔使用独立陶瓷材质，龙头与五金使用金属材质。外置盆从直角方坑改为连续圆角、斜壁与排水坡度；主卫一体盆保留现有构造并校准材质。次卫补上地漏、拉手和纸架。
- 厨房保留双眼燃气灶，增加 28 cm 浅煎锅、22 cm 带盖汤锅、砧板与两只叠碗。锅具放在锅架上，把手避开旋钮，保留备餐空间。水槽变为圆角拉伸金属槽体，底面朝原排水盖落坡。
- 接触阴影、日光、Cycles 漫反射及 HDR 反射全部按最终模型重新生成。新增小尺寸次卫和厨房局部反射，不增加逐帧反射捕捉、阴影或后期渲染通道。

- 全屋玻璃窗和玻璃门补充嵌玻密封条，矩形型材增加真实小圆角，门执手增加底座、连接杆与圆角握柄。压纹玻璃移除不透明棕灰底图，保留原压纹法线并恢复透光。
- 厨房在真实外窗开口处增加有限面积的离线日光输入；烘焙中清玻璃和隐私玻璃的阴影透射也分别检查。

## 验证与边界

保留原节点变换、交互元数据及显示状态；1.4 m 视角、取消碰撞、餐桌无花瓶、默认打开的主卫隔断及房间入口位置均不改动。新增六个物件节点与 20 处嵌玻密封条节点；活动玻璃自身带交互状态时，密封条同步继承状态。原始来源为 main 9c851f3；编辑源为 source/home-deco-details.blend。

模型与贴图继续共享和压缩，20 MB 为用户认可的体积参考，而非硬性失败阈值。加载仍需全屋几何与光照准备完成后揭示画面；没有把分模块存储误称为当前首屏按房间加载。局部反射是静态环境近似，不是实时镜面或完整实时全局光照。

最终几何为 1,412 个 Mesh 节点、600,569 个三角形（相对开始时 568,029 增加 5.7%）。12 个模块与 55 张共享贴图合计 7,155,873 字节，连同所有外观资源共 12,978,494 字节。清理了无引用的旧生成资源。

模块校验确认解码后的属性/索引、原有局部变换和元数据一致；1,157 个未修改对象的包围盒保持不变。20 组玻璃/胶条在房门、主卫隔断和厨房窗开关后相对变换误差低于 3e-15。九个房间入口和重点入口的一米路径检查通过。故意延迟或丢失光照资源时，loading 行为正常，第一帧与稳定照明帧一致。

实时玻璃优化：8 个相关玻璃网格经焊接边检查均为闭合薄实体，原本已经包含两侧表面；运行时使用 FrontSide 避免再次渲染背面。折射缓冲采用主画面线性分辨率的 0.35，保留压纹/磨砂效果。几何与外部窗框仍按主画面分辨率绘制。


最终性能测试使用 Chrome / Apple M4、1920×1080 CSS 视口和 DPR 2，自适应实际缓冲为 2065×1161，折射缓冲比例 0.35。餐厅、客厅、次卫、主卧、厨房分别采样 300 帧，来回行走并摆动视角：五处帧间隔中位数均约 16.7 ms，P95 为 16.7–16.8 ms，1,500 帧内无超过 25 ms 的帧。该结果只代表这台机器与这些路线，不是手机或所有设备保证。见 [性能数据](detail-performance.json)。

生产构建在模拟 4 MiB/s 下载和 40 ms 延迟的本机预览中，冷加载至可交互为 4.36 秒，缓存加载为 2.05 秒。是网络模拟结果，不是 GitHub Pages 的实际公网测速。见 [加载数据](detail-loading.json)。

构建、资源完整性/烘焙版本、模块几何、加载进度、灯光首帧、门窗开合、房间入口检查均通过；浏览器捕获无页面/着色器错误。最终照明源保存在 `source/home-deco-details-daylight.blend`，模型编辑源在 `source/home-deco-details.blend`。本轮 goal 在本地完成，未提交或发布。
